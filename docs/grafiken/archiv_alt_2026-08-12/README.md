# Archivierte alte Grafikstände

Diese Dateien stammen aus früheren Matrixgrafikläufen. Sie werden seit der
stufenspezifischen Auswertung vom 12.08.2026 nicht mehr in Exposé oder PA
eingebunden. Sie bleiben für historische Vergleiche und Nachvollziehbarkeit
erhalten.

Insbesondere dürfen die früheren gemeinsamen Übersichten nicht als aktuelle
SuGaR-Coarse-Nachweise gelesen werden, wenn eine Zeile nur aus
`sts_masked.json` gespeist wurde.
